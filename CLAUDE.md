## Project Overview

This is the Minds front-end web application - an Angular 19 application for a social media platform with Web3 integration, real-time messaging, content management, and monetization features.

## Essential Commands

### Development
```bash
# Install dependencies
npm install

# Start development server with HMR and proxy (client-side only)
npm run serve:dev

# Run unit tests
npm test

# Test SSR (Server-Side Rendering):
# 1. Build first
npx ng build minds --configuration production
# 2. Then run the SSR server
npm run serve:ssr

# Run specific test file
npm test -- --include='**/path/to/test.spec.ts'

# Check code formatting
npm run lint

# Auto-fix code formatting
npm run lint:dev

# Generate GraphQL types (run when GraphQL queries change)
npm run graphql:codegen:compile:engine  # For main API
npm run graphql:codegen:compile:strapi   # For Strapi CMS

# Run Storybook for component development
npm run storybook
```

### Building
```bash
# Production build (includes both browser and server/SSR builds)
npx ng build minds --configuration production

# Development build with watch mode
npm run build:dev

# Build with specific configuration
npx ng build minds --configuration development
```

## Architecture & Structure

### Core Technologies
- **Framework**: Angular 19 with TypeScript
- **State Management**: RxJS, Apollo Client for GraphQL
- **Styling**: SCSS, Angular Material, Material Design Lite
- **Real-time**: Socket.io for messaging
- **Web3**: Ethers.js, WalletConnect for blockchain features

### Directory Structure
```
/src/app/
├── common/          # Shared modules, services, directives, pipes
├── modules/         # Feature modules (70+ modules including):
│   ├── auth/       # Authentication & registration
│   ├── newsfeed/   # Main feed functionality
│   ├── channels/   # User profiles
│   ├── groups/     # Group functionality
│   ├── messenger/  # Chat/messaging
│   ├── wallet/     # Payments & blockchain
│   ├── boost/      # Content promotion
│   └── ...         # Many more feature modules
├── services/       # Core application services
├── helpers/        # Utility functions
└── interfaces/     # TypeScript interfaces
```

### Key Services & Patterns
1. **Client Service** (`src/app/services/api/client.ts`) - Main API client wrapper
2. **Session Service** - User authentication state management
3. **Apollo GraphQL** - Two configured clients:
   - Default client for main Minds engine API
   - 'strapi' named client for CMS API
4. **Feature Modules** - Each major feature is a lazy-loaded module
5. **Dependency Injection** - Extensive use of Angular DI for services

### GraphQL Integration
- GraphQL queries use `.engine.graphql` extension for main API
- Strapi queries use `.strapi.graphql` extension
- Generated types in `src/graphql/generated.engine.ts` and `generated.strapi.ts`
- Always regenerate types after modifying GraphQL queries

### Testing Approach
- **Unit Tests**: Karma + Jasmine, mocks in `src/tests/`
- **E2E Tests**: CodeceptJS with Playwright in `e2e/test/`
- Test files should be co-located with source files as `*.spec.ts`

### Development Environment
- Proxy configuration in `proxy.conf.js` routes API calls to backend
- Hot Module Replacement (HMR) enabled in development
- Environment configs in `src/environments/`

### Build System
- **SASS Compilation**: `npm run prebuild:dev` or `npm run prebuild` compiles SASS files via Gulp
- **Generated Files**: `src/main.css` is GENERATED by the build process - DO NOT edit directly
- **Source Files**: Edit SASS files in `src/stylesheets/` instead of generated CSS
- **Build Dependencies**: `build:dev` runs `prebuild:dev` automatically to generate CSS

## Important Conventions

1. **Code Formatting**: Prettier is enforced - always run `npm run lint:dev` before committing
2. **Module Structure**: Feature modules should be lazy-loaded when possible
3. **Service Injection**: Use `providedIn: 'root'` for singleton services
4. **GraphQL Queries**: Place in module folders with appropriate extension
5. **Component Styling**: Use SCSS with component-scoped styles
6. **i18n**: Use Angular i18n directives for translatable content

## Common Development Tasks

### Adding a New Feature Module
1. Generate module with Angular CLI: `ng generate module modules/feature-name`
2. Add routing configuration
3. Add to lazy-loaded routes in app routing
4. Create GraphQL queries if needed and regenerate types

### Working with GraphQL
1. Write queries in `*.engine.graphql` or `*.strapi.graphql` files
2. Run appropriate codegen command to generate TypeScript types
3. Import generated types and use with Apollo services

### Debugging Tips
- Browser DevTools with Angular DevTools extension
- Source maps enabled in development
- Sentry integration for error tracking in production
- Console logging stripped in production builds
